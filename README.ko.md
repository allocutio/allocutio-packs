# Allocutio 팩

Allocutio 영어 학습 앱의 콘텐츠 팩과 시험·연습 콘텐츠를 공유하는 공개 목록입니다.

**현재 상태:** 아직 등재된 팩이 없습니다. 각 팩이 아래 등재 절차를 통과하기 전까지 `packs.json`은 빈 목록입니다.

## 들어 있는 것

| 파일 | 용도 |
|---|---|
| `packs.json` | 앱이 읽는 팩 목록입니다(설정 › 콘텐츠 팩 › 커뮤니티 팩). 지금은 비어 있습니다. |
| `LISTING.md` | 팩을 등재하고, 다시 점검하고, 목록에서 빼는 방법입니다. |

## 앱이 쓰는 방식

앱은 등재된 팩을 HTTPS로 zip 파일로 내려받고, 설치하기 전에 sha256을 확인합니다. Git 저장소를 복제하지 않습니다. 내려받은 뒤에는 자체 팩 검사를 실행하며, 학습 진도는 팩마다 따로 저장됩니다.

## 라이선스

등재된 팩은 각자 목록 항목과 번들 안에 라이선스를 밝힙니다. 라이선스 확인이 끝나기 전에는 어떤 팩 내용도 이곳에 올리지 않습니다.
